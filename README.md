# CodeStreak

> **CodeStreak** é o nome definido para o projeto.

Um aplicativo web para pessoas que já têm contato com programação e querem manter suas habilidades afiadas por meio de práticas rápidas e envolventes.

## A ideia

Conceitos de programação e sintaxe são fáceis de esquecer quando não são usados com frequência. Este projeto busca facilitar a revisão desses conhecimentos com um desafio diário e desafios aleatórios para praticar a qualquer momento.

A experiência se inspira em aplicativos de aprendizado diário: criar um hábito, praticar em sessões curtas e tornar o progresso motivador. O público inclui desde pessoas com conhecimentos básicos de programação até desenvolvedores júnior.

## Experiência inicial

- **Pergunta diária:** Um exercício mais elaborado, como completar um código ou desenvolver uma solução.
- **Desafios aleatórios:** Exercícios curtos que podem ser praticados a qualquer momento.
- **Temas dos desafios:** Sintaxe e conceitos de linguagens, escolha de abordagens para diferentes situações e melhoria de código — por exemplo, encontrar maneiras de simplificar ou refatorar um método muito extenso.
- **Dificuldade inicial:** Começar com perguntas e desafios acessíveis e ampliar a dificuldade ao longo do tempo.

## Público

Pessoas que já têm contato com programação, desde quem possui conhecimentos básicos até desenvolvedores júnior, e buscam uma forma rápida de revisar conceitos e continuar praticando.

## Plataforma e idioma

- **Plataforma:** Web para o protótipo inicial.
- **Idioma do aplicativo:** portugues.
- **Linguagens de programação abordadas:** A definir. Java será o ponto de partida por ser a linguagem com a qual o criador tem mais familiaridade, mas o projeto não ficará limitado a ela.

## Objetivo do protótipo em quatro semanas

Desenvolver um protótipo web funcional em quatro semanas. O escopo exato das funcionalidades e a abordagem técnica ainda serão definidos.

## Decisões em aberto

- Quais linguagens de programação serão incluídas primeiro.
- Formatos exatos dos desafios e como as respostas serão avaliadas.
- Escopo do primeiro protótipo funcional.
- Tecnologias e estratégia de publicação.
- Inclusão de contas, acompanhamento de progresso, sequências diárias ou outros recursos de motivação na primeira versão.

## Status

Conceito inicial. Os detalhes do produto serão refinados à medida que o projeto avançar.
